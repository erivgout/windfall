# Clip pitch scale

The audio clip inspector halves or doubles the selected clips' pitch. Half
moves a clip toward unison, and unison stays in unison. Double stops at 48
semitones up or down. Pitch is still a tape speed.

Each update patches only pitch. Gain, pan, and fades stay as they are. Octave
down, fifth down, unison, fifth up, and octave up stay as they are. The buttons
are hidden when a selected clip uses spectral stretch.
