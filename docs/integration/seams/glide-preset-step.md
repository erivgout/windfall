The piano-roll portamento commands step each selected note from a 16th toward a
half note. A 16th stays a 16th when moved previous. A half note stays a half note
when moved next. A duration between two presets moves to the neighboring preset.
A note with no expression counts as a 16th. A note already at the end stays as it
is while another selected note can still move. Release and articulation stay as
they are.
