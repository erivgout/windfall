The piano roll halves or doubles selected notes from their end. The end stays where it is while the start and length change together. Half rounds down and keeps at least one tick. Double stops at the start of the pattern. A note that already begins at tick 0 stays there when doubled. Notes whose end passes the pattern limit are omitted, and an empty or unchanged selection does not dispatch an edit.

The start command still keeps the length. The length command still keeps the start. Keys and expression stay as they are.
