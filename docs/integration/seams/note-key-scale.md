The piano roll halves or doubles how far each selected note sits from C5. C5 stays at C5. Half of one step above or below C5 lands on C5. Double stops at MIDI key 0 and MIDI key 127.

Starts and lengths stay as they are. Only the key is patched; velocity and expression stay as they are. Empty selections and selections whose keys would all stay unchanged do not dispatch an edit. Octave transpose still moves notes by twelve keys.
