The time signature field halves or doubles the beats per bar. Halving rounds
down, and one beat stays one beat. Double stops at 16. The beat unit stays as it
is, copied from the latest time signature when a button is clicked. A button
is disabled when it would leave the beats per bar unchanged.

The 4/4, 3/4, 2/4, 6/8, 5/4, 7/8, and 12/8 presets still set both numbers
together.
