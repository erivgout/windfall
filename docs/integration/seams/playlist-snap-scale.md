The playlist snap control moves one grid finer or one grid coarser through
step, beat, and bar. Step stays step when made finer. Bar stays bar when made
coarser. Snap off stays off, and these buttons do not turn it on. Step, beat,
and bar still update the shared snap, so the piano roll follows those three.
The piano roll's smaller divisions are unchanged by this control until a
shared value is chosen.
