The mixer recording panel steps one track's recording source from the dry
hardware input through after track effects toward after the fader and pan.
The dry hardware input stays the dry hardware input when moved previous.
After the fader and pan stays there when moved next.

Choosing the dry hardware input with no input device disarms the track.
The input device, monitor, gain, buffer, and offset stay as they are. Each
click reads the latest track recording. The buttons stay disabled while
recording or input monitoring is running, including while either store is busy.
