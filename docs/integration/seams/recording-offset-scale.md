The mixer recording panel halves or doubles one track's recording offset.
Half moves it toward no offset without rounding, and no offset stays at no
offset. Double stops at 1000 ms either way.

The buttons stay disabled while recording or input monitoring is running,
including while either store is busy. Each click reads the latest track
recording and replaces only its offset. Arm, the input route, the monitor
level, and the monitor buffer stay as they are. The recording dialog offset
stays as it is. Positive values still advance this track's captured audio.
