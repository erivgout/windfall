# Root key scale

The sampler sound section halves or doubles how far the root key sits from
C5. C5 stays at C5. Half of one step above or below C5 lands on C5. Double
stops at MIDI key 0 and MIDI key 127.

Tune and gain stay as they are. The C3, C4, C5, and C6 presets still set those
keys directly.
