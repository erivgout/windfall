## 500-insert virtualization acceptance

The remaining `scale.test.tsx` failures referenced the old scroller and the
old 128-track total. The fixture now fills **500 inserts plus Master** in a
single native batch and resets mixer selection/focus between tests. Assertions
still require only 13 strips mounted initially, 15 around an interior scroll,
bounded mounts at the final insert, and the selected out-of-view strip retained.
Tail scrolling and capacity assertions cover the new limit; no test mounts all
500 insert strips. Height, routing popover, keyboard focus and channel-link
checks are preserved.

This larger acceptance test exposed a real toolbar performance defect:
the toolbar recomputed `outputChoices` for every candidate target within
`tracks.filter`, repeating a complete graph walk hundreds of times per render.
Selecting a strip exceeded 5 seconds and five keyboard moves still timed out
with a diagnostic 30-second timeout. The toolbar now calculates each selected
source's valid target IDs once and intersects those sets. It preserves the
original exclusion of selected sources and routing-loop targets.

Final command: `bun run test src/features/mixer/scale.test.tsx --maxWorkers=1`
with the original default timeout, **14 tests passed**, 15.05 seconds total.
Evidence: `2026-10-09-mixer-scale-final.log`. No timeout was relaxed in the tests.
ESLint on `toolbar.tsx`, `scale.test.tsx` and `test-utils.ts` exits 0.
The diagnostic timeout and initial failure logs remain as evidence of the
performance regression. The original medium-routing failure disappeared once
the timed-out keyboard test completed normally and fixtures reset selection.
